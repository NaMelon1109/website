HOW TO JOIN · 如何加入

Java 版四步上线，全程不到一分钟

01

启动游戏

打开 Minecraft Java 版启动器，进入游戏主界面。

02

多人游戏

点击「多人游戏」→「添加服务器」。

03

填写地址

服务器地址栏输入：
minecraftmelon.dpdns.org
端口保持默认 25565。

04

加入世界

保存后双击服务器条目，即可进入西瓜世界，开玩！🍉
